Build a Reproducible Project: Unix + R

A one-day, hands-on walkthrough: take raw data from a download link to finished figures and an HTML report, using the shell and R, and fix the bugs along the way.

One session · about 2.5 hours Shell + R + RStudio 8 planted bugs to find
What You'll Do

You've just been handed three years of bird survey data from 12 sites around the Palouse. Your job is to turn it into a small, reproducible research project: organized folders, scripts for every step, summary tables, figures, and a report you can open in any web browser.

Along the way, some of the scripts have bugs planted on purpose. Finding and fixing them is the point: reading error messages, checking your output, and noticing when something runs without errors but is still wrong are the skills you'll use every day in real research.

This session puts together everything from the Unix and R lessons: navigating and creating directories, downloading files, pipes and loops, shell scripts, data frames, dplyr, and ggplot2.

The dataset

You'll download the data during the session with one command, so there's nothing to download ahead of time. If you want to peek at it:

bash
curl -LO https://galaxy154.github.io/unix-r-project-day/data/bird_surveys.tar.gz

Windows users: if you use WSL, you'll build the project on your Windows Desktop (/mnt/c/Users/<you>/Desktop) so that RStudio can open it too.

Using AI in This Workshop AI

Green AI Prompt boxes have prompts you can copy into Claude, ChatGPT, or Gemini. AI is welcome for the bug hunt too, with one rule: you have to be able to explain the fix in your own words.

Give context

Say what you're using ("bash on WSL Ubuntu", "R with dplyr") and what you're trying to do.

Paste the exact error

Copy the whole error message, not a paraphrase. The wording usually points right at the problem.

Show your data

Paste names(df) or head(df) so the AI uses your real column names instead of guessing.

Check the answer

Run it and compare with the expected output. "No error" is not the same as "correct."
